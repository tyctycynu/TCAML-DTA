# TCAML-DTA

**Task-Characteristic-Aware Geometric Meta-Learning for Few-Shot Drug-Target Affinity Prediction**

---

## 📋 Overview

TCAML-DTA is a geometric meta-learning framework for few-shot drug-target affinity prediction. It integrates 3D structural information of drugs and protein pockets with task-adaptive inner-loop learning rate modulation based on three task characteristics: Structural-Affinity Alignment (SAA), Distributional Novelty (DN), and Supervisory Signal Dispersion (SSD).

## ⚙️ Quick Start

### 1. Environment Setup

```bash
# Clone repository
git clone https://github.com/ljatynu/TCAML-DTA.git
cd TCAML-DTA

# Create and activate conda environment
conda create -n kdbnet python=3.10
conda activate kdbnet

# Install PyTorch
pip install torch==2.5.0 torchvision==0.20.0 --index-url https://download.pytorch.org/whl/cu121

# Install dependencies
pip install -r requirements.txt

# Set Python path
export PYTHONPATH=$PWD:$PYTHONPATH
```

### 2. Data Download and Preparation

```bash
# Download dataset
wget https://www.dropbox.com/s/xxxxxxxx/data.tar.gz

# Extract data files
tar -xzf data.tar.gz

# Verify data integrity
python scripts/check_data.py --dataset davis --dataset kiba
```

## 📊 Dataset Structure

### Davis Dataset (`data/DAVIS/`)

| File | Description |
|------|-------------|
| `davis_data.tsv` | Kinase-drug binding affinity data |
| `davis_protein2pdb.yaml` | Mapping from kinase names to PDB structures |
| `davis_cluster_id50_cluster.tsv` | Protein clustering results for sequence-based split |

**Data format example:**
```
drug    protein    Kd    y
5291    AAK1       10000  5
```

### KIBA Dataset (`data/KIBA/`)

| File | Description |
|------|-------------|
| `kiba_data.tsv` | Kinase-inhibitor binding affinity data |
| `kiba_uniprot2pdb.yaml` | UniProt to PDB mapping |

### Structure Data (`data/structure/`)

| File/Dir | Description |
|----------|-------------|
| `pockets_structure.json` | Kinase pocket 3D structures |
| `davis_mol3d_sdf/` | 3D molecular structures for Davis (SDF format) |
| `kiba_mol3d_sdf/` | 3D molecular structures for KIBA (SDF format) |

### Pretrained Embeddings (`data/esm1b/`)

Protein sequence embeddings generated by ESM-1b model (`.pt` format)

## 🚀 Model Training

### Run TCAML-DTA

Execute the following script in the `kdbnet/` directory:

```bash
cd kdbnet
CUDA_VISIBLE_DEVICES=0 python run_example.py --task davis --split_method random --support_size 5 --load_pretrained
```

### Training Details

| Parameter | Description |
|-----------|-------------|
| Dataset | Davis or KIBA kinase-drug binding affinity dataset |
| Split Methods | `random`, `protein`, `drug`, `both`, `seqid` |
| Few-shot Setting | 5-shot or 1-shot |
| Meta-training Epochs | 100 |

### Output

- Evaluation metrics (MSE, CI, R², Spearman, Pearson) printed in terminal
- Predicted binding affinity values saved as TSV in output directory
- Task-adaptive learning rate modulation analysis figures
